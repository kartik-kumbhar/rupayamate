# 💰 RupayaMate – Personal Finance Management System

RupayaMate is a personal finance management web application built using the **MERN stack**.  
It helps users track their **income and expenses**, view **financial analytics**, and control spending by setting a **monthly expense limit**.

--- 

## 🚀 Live Demo
🔗 https://rupayamate.vercel.app

---

## 🚀 Key Features

- 🔐 JWT-based secure authentication
- ➕ Add and manage income & expense transactions
- 📊 Dashboard with:
  - Total income, expenses, and balance
  - Monthly analytics
  - Category-wise expense breakdown
- 🚨 Monthly expense limit feature
- 👤 User-specific data isolation
- 🌐 Deployed on Vercel

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Token)
- **Deployment:** Vercel

---

## 📊 Dashboard Overview

The dashboard provides:
- Summary of income and expenses
- Current balance
- Monthly transaction analytics
- Category-wise spending analysis
- Monthly expense limit tracking

---

## ⭐ Conclusion

RupayaMate is a practical MERN stack project focused on real-world finance management, showcasing **secure authentication**, **CRUD operations**, **analytics**, and **deployment skills**.
